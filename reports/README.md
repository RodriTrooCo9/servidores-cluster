# Reportes de Auditoría de Infraestructura y Puertos

Este directorio almacena reportes generados automáticamente por playbooks y diagnósticos.

## Archivos
- **`port_audit_inventory.csv`**: Mapeo y estado de los puertos de red y servicios en los 8 nodos bare-metal.
- **`port_audit_full.json`**: Estructura JSON completa con metadatos de socket, protocolos y tiempos de respuesta.
